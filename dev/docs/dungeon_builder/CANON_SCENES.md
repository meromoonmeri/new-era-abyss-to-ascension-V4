## Pistes de la ROM non importées dans le mod

Ces titres sont ceux des scènes de la ROM ; leur fichier audio n'existe pas dans `Content/Music` (ni côté jeu de base). La scène se joue alors sans changer la musique — aucun titre de remplacement n'est inventé.

- `Escape Through The Snow`
- `Great Canyon`
- `Legend Of Ninetales`
- `Mt Steel`
- `Rayquazas Domain`
- `Silent Chasm`
- `Stormy Sea`
- `Theres Trouble`
- `Thunderwave Cave`


**44 Grounds canoniques**, 921 répliques canoniques référencées, 921 dont le texte est présent dans `Strings/`.

Le texte des répliques appartient à la ROM et n'est pas redistribué dans ce dépôt : importez-le depuis votre ROM EU avec `tools/audit_pmdred_eu_rom.py`, puis `tools/import_red_scene_strings.py`. Tant qu'une clé manque, la réplique est sautée en jeu — rien n'est inventé à la place.


## Fidélité : ce qui est rejoué, ce qui ne l'est pas encore

La séquence vient de `RESERVE/red_cinematics/<scene>.cif.json`, extraction du
script de la ROM. Elle donne l'**ordre exact** des évènements. Bilan sur les 44
scènes :

| Type d'évènement ROM | Volume | État |
|---|---|---|
| `Dialog` (répliques) | 930 | rejoué, texte canonique importé (930/930) |
| `Audio SWITCH` / `FADEOUT` | 155 | rejoué quand la piste existe dans `Content/Music` (56 résolues, 37 sans fichier audio) |
| `Effect SHAKE` | 147 | rejoué (`GROUND:MoveScreen`) |
| `Camera INIT_PAN` | 38 | **non rejoué** : l'extraction ne donne pas les coordonnées |
| `Animation` (anim_id) | 411 | **non rejoué** : l'extraction ne donne pas l'acteur |

Les évènements non rejoués sont comptés et journalisés en jeu
(`[RedCanonScene]`), jamais remplacés par une approximation.

### Ce qu'il manque pour la fidélité pixel-perfect complète

Les déplacements de personnages, les coordonnées de caméra, les identifiants
d'acteurs et les effets sonores ponctuels vivent dans le **bytecode du script de
la ROM**, qui n'est pas désassemblé dans `pret/pmd-red` (seuls 6 scripts le sont :
intro, titre, test de personnalité, carte du monde, écrans société, santé) et
dont l'extraction présente ici ne conserve que le type des évènements.

Les obtenir demande de décoder le script de sol de PMD Red depuis la ROM EU —
la chaîne d'extraction du dépôt (`tools/audit_pmdred_eu_rom.py`, variable
`PMDRED_EU_ROM`) fournit déjà les octets ; il reste à écrire la table d'opcodes
« ground script ». Tant que ce décodage n'est pas fait, aucune chorégraphie
n'est inventée à la place.
