# Rendus des rooms — No Name Village

Rendus depuis la source GameMaker (extraction UndertaleModTool officielle).
Les 96 pages de texture sont decodees depuis leur format BZ2+QOI, puis
chaque room est composee couche par couche dans l'ordre de `LayerDepth`.

La couche `invisible` est ecartee : elle porte la collision du jeu
(`objbwall`, `objcolwall`, `objbslope`), jamais dessinee par GameMaker.
