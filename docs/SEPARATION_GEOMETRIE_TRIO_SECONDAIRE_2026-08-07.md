# Séparation géométrique — Grotte Repos / Halles Royales / Jardin Énergie

Avant correction, les trois zones partageaient exactement le même patron sur 62 floors.

## Grotte Repos

- grilles compactes 3×4 évoluant vers 4×5 ;
- cellules 7×7, murs 5 ;
- priorité aux salles rondes (14 contre 2 salles en croix) ;
- BranchRatio 70–101 % ;
- halls 1–2, biais de virage 85 ;
- reconnexion 15 % puis décroissante.

Identité : réseau cavernicole serré, très ramifié et sinueux.

## Halles Royales

- grilles horizontales 5×3 puis 6×4 ;
- cellules 9×9, murs 2 ;
- priorité massive aux salles en croix (16 contre 2 rondes) ;
- RoomRatio élevé 85–100 % ;
- halls larges 2–4, presque rectilignes ;
- reconnexion 55 %.

Identité : architecture construite, grandes salles et galeries régulières.

## Jardin Énergie

- grilles 4×4 évoluant vers 5×5 ;
- cellules 10×10, murs 2 ;
- priorité aux grandes salles rondes (15 contre 3 croix) ;
- branchement intermédiaire ;
- halls 1–3, biais 35 ;
- reconnexion 40 %.

Identité : grands noyaux d’énergie reliés par des corridors organiques.

## Résultat

- similarité de 100 % supprimée ;
- aucun patron exact partagé entre les trois zones ;
- variation interne ajoutée par tranches de huit floors ;
- nombres de floors, spawns, objets et index inchangés.
