`arena/019ff05e-new-era-abyss-to-ascension-v4`, commit

jouable Petit Bois / Grotte Éclair / Mt Acier. Sa restauration ne constitue

  référence, mais leur certification groupée PMDO
  route/gameplay/audio/unload est explicitement `DEFERRED_NOT_EXECUTED` ;

  supplantée par
  `docs/pmdred_eu/narrative_migration/INTEGRATION_CONTRACT.md` : l'intégration
  actuelle doit rester dans la continuité New Era, sans second quiz ni seconde
  campagne ;

  gelés, les chapitres 1–5, les routes FugitiveArc ou les 27 candidats directs.
